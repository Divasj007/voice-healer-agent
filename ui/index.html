Local architecture

Every important hop stays on your machine.

◉01 · INPUT

Voice or CLI

Whisper captures an optional spoken command. Manual text keeps the full workflow usable without a microphone.

⌁02 · RUN

Python subprocess

The target is executed with bounded timeouts and captured stdout/stderr diagnostics.

✦03 · REPAIR

Local coder model

Ollama receives the traceback and source through its localhost REST API.

✓04 · VERIFY

Patch, then prove

The candidate is syntax-checked, written atomically, executed again, and rolled back if repair fails.
