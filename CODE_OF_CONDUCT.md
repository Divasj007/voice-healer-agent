# Code of Conduct

We want Voice Healer to be a welcoming open-source project.

## Expected behavior

Be respectful, constructive, patient, and specific when discussing code or ideas. Assume good intent and focus criticism on the work rather than the person.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct toward minors, or deliberate disruption of project infrastructure are not acceptable.

## Reporting

Report concerns privately to the project maintainers through the repository's available private reporting mechanism. Do not publish sensitive details in a public issue.

Maintainers may remove content, limit participation, or close contributions when behavior violates this code.
