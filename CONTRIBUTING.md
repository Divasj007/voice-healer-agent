# Contributing to Voice Healer

Thanks for helping improve Voice Healer.

## Development setup

Use Python 3.11 or newer and create a virtual environment before installing the runtime dependencies.

```text
python -m venv .venv
python -m pip install -r requirements.txt
```

The automated test suite intentionally does not require a microphone, a hosted API, or a running Ollama server.

```text
python -m unittest discover -s tests -v
```

For browser work, the UI is dependency-free and served by `ui_server.py`.

```text
python skills/voice-healer/scripts/ui_server.py --open
```

## Pull requests

Keep changes focused and document user-visible behavior. Add or update tests when changing execution, repair, routing, HTTP, or Git-hook behavior.

Do not commit `.venv/`, generated bytecode, `.bak` files, logs, secrets, or local model files.

Before opening a pull request, run the test commands from the CI workflow locally when possible.
